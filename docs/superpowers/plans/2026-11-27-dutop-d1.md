# Dutop D1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkboxes for tracking.

**Goal:** Replace the personal Python command with a tested native Rust CLI.

**Architecture:** One Cargo package separates filesystem accounting, report data,
terminal rendering and command-line handling. The scanner measures native allocated
blocks without subprocesses. The executable installs a cancellation handler and
connects the components; packaging and redesign remain later deliveries.

**Tech Stack:** Rust 2024, clap, signal-hook, unicode-width, rustix; tempfile for tests.

**Spec:** `docs/superpowers/specs/2026-11-27-dutop-rust-design.md`

## Global Constraints

- Work in the requested `dev` branch in this checkout. No commits or pushes.
- macOS/Linux; no Python, external `du`, network requests or service at runtime.
- First-level rankings; recursive allocated totals; hidden entries included.
- Default top count 10; positive `--top N`; preserve the current two panels.
- No following nested symlinks; deduplicate hard links in the complete total.
- Focused tests only; reuse valid results rather than rerunning for ceremony.
- Install only after verification, with backups and scoped home-write approval.

## Review Focus

- Filenames with control codes, invalid UTF-8 and Unicode format controls must not affect the terminal.
- Huge top counts must not allocate or print billions of blank rows.
- Hard links spanning immediate files and folders must not inflate the complete total.
- Read failures, vanished files and interrupts must not masquerade as a complete report.
- Replacing a symlink at installation must not overwrite the original Python source.

## Task 1: Scan and report

`src/scan/mod.rs`, `tests/scan.rs`, `tests/support/mod.rs`.

Interfaces: `scan::scan(path: &Path, cancelled: &AtomicBool) -> io::Result<Report>`;
`Report { path, directories, files, total: u64, partial: bool, skipped: usize }`;
`Entry { name: OsString, size: u64, kind: EntryKind }`.

- [x] Write scanner fixtures asserting rankings, native-du fixture totals, totals beyond ten,

- [x] Run `cargo test --test scan`; expected all scanner tests pass. Add a deterministic
